Web Pentest

OWASP Juice Shop — Web Application Pentest

Authorized penetration test against OWASP Juice Shop 20.1.1 in an isolated local Docker lab. Two testing rounds produced 11 confirmed findings, including two critical authentication / authorization bypasses (JWT signing-key forgery, mass-assignment to admin). Reported through a structured pentest report.
